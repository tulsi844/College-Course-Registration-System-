# Student Enrollment Management System 

A full-stack web application that allows students to register for technical courses and provides administrators with a dashboard to manage enrollments in real-time.

##  Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Java, Spring Boot (REST API)
- **Data Storage:** In-Memory Storage (Java ArrayList)

##  How to Run
1. **Backend:**
   - Navigate to the `registration` folder.
   - Run `RegistrationApplication.java`.
   - The server starts on `http://localhost:9090`.
2. **Frontend:**
   - Navigate to the `javaprojectfrontend` folder.
   - Open `demo.html` using the **Live Server** extension.

##  Features
- Dynamic student registration form.
- Admin dashboard to view enrollment records.
- RESTful communication using JSON.
